# NEET Protest Analytics Dashboard

## Overview
This project analyses NEET protest and paper leak data using web scraping, data processing, and interactive dashboards.

## Technologies Used
- Python
- Selenium
- Pandas
- Supabase
- Power BI
- GitHub
- Google AI Studio (Gemini)

## Project Workflow
1. Scrape protest data using Selenium
2. Clean and preprocess the data
3. Store/manage data with Supabase
4. Visualize insights using Power BI
5. Version control with GitHub

## Files
- scraper.py – Selenium scraper
- neet_protest_dataset.csv – Cleaned dataset
- visualchart.pbix – Power BI dashboard
- visualchart.pdf – Dashboard export
